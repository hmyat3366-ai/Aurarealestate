# Vane & Sterling — Figma Design System & Site Canvas Generator

This plugin automatically builds the exact **Vane & Sterling** luxury real estate website in your Figma file, including:
1. **Figma Native Variables (Tokens)**: Colors, Spacings, Radii, Hairlines, and Badge tokens.
2. **Master Components (Library)**:
   - Header (Desktop 1440px & Mobile 390px)
   - QuickDiscoveryConsole (Search tabs, inputs, filters, and CTA)
   - PropertyCard (4:3 photo frame, badges, price, specs, hairline dividers)
   - ValuationBanner (Discreet market valuation callout)
   - Footer (Obsidian multi-column architectural footer)
3. **Complete Full-Page Artboards**:
   - `01 - Homepage (Desktop 1440px)`
   - `02 - Sell with Us (Desktop 1440px)`
   - `03 - About Us (Desktop 1440px)`
   - `04 - Contact Us (Desktop 1440px)`
   - `05 - Homepage (Mobile 390px)`

## How to Run in Figma (1-Click Setup)

### Option A: Via Figma Desktop App or Browser (Recommended)
1. Open any Figma file (or create a new blank Figma file).
2. Click the Figma menu icon (top left) or right-click anywhere on the canvas.
3. Go to **Plugins** -> **Development** -> **Import plugin from manifest...**
4. Select the `manifest.json` file located at:
   `c:\Users\Aniz Wiz Gouki\Desktop\DA\figma-plugin\manifest.json`
5. In Figma, run **Vane & Sterling Site & Variables Generator**.
6. In ~2 seconds, all Variables, Components, and Complete Artboards will be rendered on your canvas!

---

### Option B: Import Tokens via Tokens Studio for Figma
If you use the popular **Tokens Studio for Figma** plugin:
1. Open **Tokens Studio for Figma**.
2. Go to **Settings / Tools** -> **Load from File / Import**.
3. Select `c:\Users\Aniz Wiz Gouki\Desktop\DA\figma-tokens.json`.
4. Click **Apply to Selection / Document** to load the design variables.
